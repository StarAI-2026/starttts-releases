# StarTTS 更新分发仓库

本仓库是 StarTTS 桌面客户端的**更新与分发渠道**，只存放版本清单、公告与编译好的安装包，**不包含任何源代码**。

## 文件说明

- `latest.json` — 版本清单：客户端启动时自动检查，发现新版本会弹窗提示并可一键更新。
- `announcements.json` — 版本公告：每个新版本更新了什么，这里逐条写清楚，客户端打开即可阅读。
- `Releases` — 各版本下载：
  - `StarTTS_v<版本>_windows_amd64.zip` 便携版（解压即用，不覆盖已有模型与数据）
  - `StarTTS_Setup_<版本>.exe` 安装版（双击安装，推荐普通用户）

## 首次安装

1. 到本仓库 [Releases](../../releases) 页面下载 `StarTTS_Setup_<最新版本>.exe` 安装。
2. 首次启动会引导下载语音模型（约 4.3GB，仅需一次）。
3. 之后的版本更新无需回到这里下载——打开客户端点「立即更新」即可自动完成。

## 用户数据位置

模型、历史与输出保存在安装目录内（默认 `%LOCALAPPDATA%\Programs\StarTTS`），更新过程不会触碰这些数据。
